候选着法

    棋盘可以走子。评估条、金色箭头和主变来自页面里的浅层搜索，只为看清分析台长什么样。安装后的程序用本机 Pikafish 和随包的神经网络权重做深度解算，并能列出 MultiPV、节点速率和哈希占用。

    壹

    同一张桌子上的四种用法

    打开程序先见到这四扇门。引擎在进入时于后台就绪，计算不出这台电脑。

    1. 壹

      人机对战

      与本机 Pikafish 对弈。开局前可以选择执红或执黑。对手的思考可以限制在单步时间、搜索深度或计算节点。

      走法指引把推荐着法画在棋盘上。可以悔棋、翻转视角。拾子、落子、吃子、将军、终局、悔棋和开局各有音效，顶栏可以静音。

    2. 贰

      同屏对弈

      两个人在同一台电脑上轮流走子，不需要网络。棋盘、音效、悔棋和翻转都还在。

    3. 叁

      复盘打谱

      棋谱回放只浏览，不改谱。手动打谱时，若在历史局面走出新着，原主线留在变化树上，同级变着可以切换，也能一键回到主线。

      对战里下过的棋可以同步进来。导航有起点、上一步、下一步和终点。复盘使用自己的棋盘，不改动正在进行的对局。

    4. 肆

      残局研究

      三种方式：双方手动推演、与引擎对抗、自由摆棋。摆棋时可放入帅、仕、相、马、车、炮、兵，以及将、士、象、马、车、炮、卒，也可以擦掉棋子。

      内置六个局面：初始全盘、马兵胜单缺象、炮兵胜双士、车兵胜单车、三兵胜士象全、单马胜单士。当前局面的 FEN 可以复制，也可以把一串 FEN 贴进来载入。

    贰

    分析台把一步棋摊开

    对局时，右侧有三个页：对局棋谱、AI 分析、FEN 工具。棋谱按红黑分行，用中文记谱，点任意一步可以跳回去。

    搜索与候选

    分析可以一直算下去，也可以按深度、时间或节点停下。这些限制和对战里引擎的思考限制是分开的。

    MultiPV 同时给出多条候选。快捷档是 1、2、3、5 线，设置里可以选择 1 到 5 条。点一条路线，棋盘上的箭头跟着换。

    面板显示搜索深度、红方视角的评分、每秒节点、节点数、耗时和哈希占用。子力分写成正负小数，杀棋写成 M+n 或 M-n。左侧评估条用同一套分数：红方向下增长，黑方向上增长。

    引擎怎么调

    线程数按本机逻辑核心给出默认值，并给界面留出余量。哈希表默认 128 MB，可以调大，也可以清空。

    Skill Level 从 0 到 20，数值越低越容易走软，20 是满强度。打开限制棋力后，Elo 滑杆从 1280 到 3133。

    重复局面可以按亚洲象棋联合会规例、中国规则、天天象棋、计算机对弈、弈天棋缘、允许捉子，或不判定重现来处理。引擎报告的其余 UCI 选项在高级参数里改。设置记在本机，引擎进程可以重新启动。

    它在什么机器上跑

    安装包面向 Windows 10 或 Windows 11 的 64 位系统，并附带 BMI2 与 AVX2 两套引擎。程序按文件名依次寻找，先用 BMI2。

    界面由 Tauri 2 承载，在 Windows 上通过系统 WebView2 显示。神经网络权重是随包的 pikafish.nnue。

    程序由什么写成

    界面是 Vue 3 与 TypeScript，状态放在 Pinia，桌面壳是 Tauri 2，引擎进程由 Rust 通过 UCI 管理。

    Xiangqi Studio 以 GPL-3.0 发布。Pikafish 及其权重属于上游项目，许可文本在安装包的 licenses 目录，也见 Pikafish。本工作室不声称拥有引擎或权重。

    从源码构建时，仓库要求 Node.js 24、pnpm 11，以及 Tauri 2 所需的 Rust 工具链。
